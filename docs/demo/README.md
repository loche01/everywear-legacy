# everyWEAR 기능 시연

원본 상품 데이터와 샘플 데이터를 넣은 로컬 서버에서 사용자·관리자 기능을 실제로 실행하고 촬영한 기록입니다. 시연 영상 대신 화면 79장으로 기능 흐름을 정리했습니다.

> 같은 내용을 PDF로도 볼 수 있습니다: [everyWEAR-demo.pdf](everyWEAR-demo.pdf)

## 표시 기준

| 표시 | 의미 |
|---|---|
| 🟦 DB 연동 | DB 데이터를 조회해 표시하는 화면 |
| 🟩 화면에서 실행 | 버튼을 눌러 실제로 데이터를 바꾼 단계 |
| 🟨 원본 디자인 예시 | DB와 연결되지 않은 원본 고정 화면 |
| 🟥 외부 설정 필요 | 문자 발송 등 외부 서비스 설정이 있어야 끝까지 동작 |

## 시연 환경

| 항목 | 내용 |
|---|---|
| 서버 | 로컬 Tomcat 9, Java 21 |
| DB | 로컬 MySQL 8 (`everywear_recovery`) |
| 사용자 계정 | 테스트 계정 `recovery_user` |
| 관리자 계정 | 테스트 DB에서만 만든 계정 + 이메일 인증번호. 공개 SQL에는 넣지 않았습니다. |

## 샘플 데이터

- 회원 5명: 정상 3, 탈퇴 1, 로그인 실패 잠금 1. 테스트 계정의 프로필도 채웠습니다.
- 주문 8건과 결제·배송 각 8건. 배송준비중, 배송중, 배송완료, 비회원 주문을 포함합니다. 결제는 테스트 결제창까지만 동작해 주문이 만들어지지 않으므로, 주문은 SQL로 넣었습니다.
- 환불 2건(신청됨, 완료), 리뷰 2건과 사진 1장, 문의 2건과 관리자 답변 1건, 공지 3건, 장바구니 2건, 찜 3건
- 샘플 회원·주문의 이름, 연락처, 주소는 모두 만든 값입니다.
- 실제 계정으로 로그인한 소셜 로그인·관리자 인증 화면의 이메일, 회원번호, 이름은 검은 상자로 가렸습니다.
